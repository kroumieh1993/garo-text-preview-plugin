# Changelog

All notable changes to the Garo Text Preview Plugin will be documented in this file.

## [1.0.0] - 2024-12-12

### Added
- Initial release of Garo Text Preview Plugin
- Font management system with support for Google Fonts and custom fonts
- Product-level text field customization with multiple fields per product
- Character limit validation (minimum and maximum)
- Additional pricing per customization field
- Image positioning system (X/Y coordinates)
- Required field validation
- Image upload functionality for products
- Global fields system for applying fields to all products or specific categories
- Real-time text preview with selected fonts
- Frontend validation with error messages
- Cart integration with customization display
- Checkout integration with price calculations
- Order management with customization details in admin
- Responsive design for mobile devices
- Admin interface for easy configuration
- Comprehensive documentation

### Features
- Multiple text fields per product
- Single font selection per product (applied to all fields)
- Min/max character limits per field
- Additional cost per field
- Image placement coordinates
- Image upload option
- Global fields for all products
- Category-specific fields
- Real-time preview
- Cart/checkout integration
- Order tracking

### Technical
- WordPress 5.8+ compatibility
- WooCommerce 5.0+ compatibility
- PHP 7.4+ support
- Object-oriented architecture
- Proper sanitization and validation
- Security best practices
- AJAX support (ready for future enhancements)
- Modular codebase

### Documentation
- Complete README with usage instructions
- Installation guide
- Code comments
- Hook documentation
